`redsun.compute` runs a component's calls in worker processes the session shares between its components. A component asks for a `ProcessExecutor` in its constructor or its `setup`, and each call runs in a worker started as `python -m redsun.workers`. The module also exports `ProcessPool`, `ProcessPoolSettings`, `Priority` and `WorkerCrashed`, which a call raises once it has ended 3 workers. The `compute` section of a session file gains `processes`, the number of workers, and `priority`, the priority they start at (`low`, `normal` or `high`). The `inline_processes` fixture of `redsun.testing` runs each call in the test's thread after a pickle round trip.

```python
class MyController:
    def __init__(self, name: str, executor: ProcessExecutor) -> None:
        self._executor = executor

    def process(self, frames: list[np.ndarray]) -> None:
        self._executor.submit(fit, frames).then(self.sig_fit.emit)
```
