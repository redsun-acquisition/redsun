A view takes a `title`, the text the window shows for it in place of its name: a class attribute, a `redsun.Declare` keyword or a `title` key of its session-file entry. `redsun.qt.attach` takes the titles as its `titles` keyword.

```python
class MyView(QWidget):
    placement: Placement = Dock("left")
    title = "Commands"
```
