`redsun.testing.qt` is a `pytest` plugin for testing Qt components, installed with the `testing-qt` extra. It defines a `qapp` fixture. `emit_queued_on_main_thread` delivers on the main thread the `psygnal` emissions queued from other threads, whichever plugin supplies `qapp`. `release_slots_after_module` releases the slots of the widgets freed after each test module, which `pyqt6` otherwise holds until the process exits.
