A session file is checked for more when it is loaded, and its JSON Schema says more. Loading refuses a `workers` on a presenter or view that is not a whole number of at least 1, an `actions` that is not a list of mappings, and a `color_scheme` other than `system`, `light` or `dark`. The session-file schema refuses `plugin_name` without `plugin_id`, the reverse, and a misspelled `plugin_*` key, and the plugin-manifest schema refuses a class not written as `module:ClassName`.
