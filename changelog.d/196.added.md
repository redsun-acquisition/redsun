Add `redsun.qt.styles.qlementine.QlementineStyle`, a `configure_application` hook provider giving a Qt session `qlementine`'s look, in its dark or light theme as the colour scheme reads; a session file names it `qlementine`, and `redsun --example qlementine` shows it. The `qlementine-pyqt` and `qlementine-pyside` extras install the package it needs.
