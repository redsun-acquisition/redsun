The `pyside` extra installs `pyside6-essentials` instead of the whole `pyside6`, so the PySide6 add-on modules (QtCharts, QtMultimedia, QtSerialPort, QtWebEngine and others) are no longer installed with it; a project using one adds `pyside6` to its own dependencies. A uv-managed environment that had `pyside6` loses files `pyside6-essentials` shares when `uv sync` removes it, and then finds no Qt binding: repair it with `uv sync --reinstall-package pyside6-essentials`, or `pip install --force-reinstall --no-deps pyside6-essentials`.
