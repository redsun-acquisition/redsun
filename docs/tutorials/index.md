# Tutorials

If you're new to `redsun`, start here. Over nine tutorials you build one
application step by step, so follow them in order: each one adds to the
script you finished in the one before.

| Tutorial | You end with |
| --- | --- |
| [Installation](installation.md) | a project folder with `redsun` installed |
| [Writing your first session](first-session.md) | a window that shows a stage and moves it |
| [Describing a device with a protocol](device-protocols.md) | a second stage, moved by the same presenter and view |
| [Building controls for a plan](plan-controls.md) | a plan, and the controls to run it on the stage you choose |
| [Acquiring images](acquire-images.md) | frames on disk, and one in the window |
| [Scanning a stage with the camera](scan-plan.md) | a scan that takes a frame at each position of a stage |
| [Arranging the window](window-layout.md) | the image in the centre of the window, the stages below it |
| [Putting a device behind a service](device-service.md) | a third stage, in a program of its own |
| [Reusing the built-in positioner](builtin-positioner.md) | the stages moved by the positioner `redsun` ships |

You don't need any hardware for these tutorials.
