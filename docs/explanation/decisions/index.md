# Architectural Decision Records

Each record states one decision about how `redsun` is built, in the format
[Michael Nygard](http://thinkrelevance.com/blog/2011/11/15/documenting-architecture-decisions)
describes: status, context, decision, consequences. An accepted record is
never edited; a later one replaces it.
