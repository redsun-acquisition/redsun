# Changelog

What changed in each release, grouped as in
[Keep a Changelog](https://keepachangelog.com/en/1.0.0/). This project follows
[Semantic Versioning](https://semver.org/spec/v2.0.0.html), and dates are
written `DD-MM-YYYY`.

Each section lists the pull requests merged for that release. A change that
breaks existing code is marked **Breaking**, and
[Migration](../migration/index.md) shows how to move code across it.
Releases up to 0.13.0 are in the [previous changelog](previous-changelog.md).
