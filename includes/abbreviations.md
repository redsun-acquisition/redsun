*[ADR]: Architecture Decision Record. A numbered page recording one decision and the reasons for it.
*[DI]: Dependency injection. The session hands a component what it asks for, instead of the component making it.
*[DVP]: Device-View-Presenter. The way a redsun session is organised.
*[MVP]: Model-View-Presenter. The pattern DVP comes from, with devices in place of the model.
*[hook point]: A named point in a session's life, such as the build or the closing of the window, at which the session calls one of your objects.
*[structural subtyping]: Deciding whether a class fits by the members it has, not by what it inherits from.
*[EPICS]: A set of tools for controlling instruments over a network.
*[IOC]: Input/output controller. The EPICS server program that offers values, most often read from hardware it controls.
*[PV]: Process variable. One named value an IOC offers.
