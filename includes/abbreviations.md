*[ADR]: Architecture Decision Record. A numbered document recording one decision and the reasoning behind it.
*[DI]: Dependency injection. A container supplies a component with what it needs, rather than the component constructing it.
*[DVP]: Device-View-Presenter. The architecture a redsun session is built on.
*[MVP]: Model-View-Presenter. The architecture DVP is a variation of, whose Model layer DVP replaces with a Device layer.
*[hook point]: A named moment in the build at which a session's own object is called.
*[structural subtyping]: Conformance decided by the members a class has, not by what it inherits from.
*[virtual container]: The session-wide signal bus, provider registry and document-callback registry.
